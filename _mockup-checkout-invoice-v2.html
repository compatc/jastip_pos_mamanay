📋 Yang berubah di aplikasi (rencana implementasi)

  • Tombol checkout: Kirim Pesanan → Pesan Sekarang (Catalog.tsx, teks tombol saja, warna & fungsi tetap).
  • Setelah submit sukses → langsung navigate('/invoice/{id}') — modal "Pesanan Terkirim!" dihapus, diganti toast kecil "✓ Pesanan terkirim!" muncul 2 detik di halaman invoice.
  • Tampilan Invoice.tsx digaya "Invoice Belanja" formal: header brand jastip_mamanay / Invoice Penjualan + INV-XXXXXX + tanggal, kartu status pill + progress (Dibuat → Menunggu Bayar → Dikemas → Selesai), kartu pelanggan, kartu item dengan badge READY/PO, rincian total, kotak Sisa Tagihan + QRIS + tombol bayar.
  • Kotak bayar = tab ▣ Bayar QRIS / 🏦 Transfer BCA (sama seperti Invoice.tsx sekarang): QRIS menampilkan QR dinamis + countdown + "Menunggu pembayaran…"; BCA menampilkan no. rekening 5271330651 + nominal persis + tombol Upload Bukti Transfer.
  • Kartu 🚚 Metode Pengiriman (sudah ada, dipertahankan): pilihan radio 📮 Kirim Manual (JNT/JNE/LION, admin atur kurir+ongkir) vs 🛒 Kirim via Shopee (checkout sendiri), plus hint "belum dipilih" & tombol chat WA.
  • Fitur lama TIDAK hilang: kode unik, poin loyalitas, tukar poin, chat WA di kartu pengiriman, Simpan PDF + Salin Link, deadline 2 hari — hanya tata letak digaya "Invoice Belanja".
  • Link invoice tetap dikirim ke WhatsApp (fallback kalau customer tutup tab). Order id tetap di URL → bisa refresh/back.
  • Alur ini sama untuk semua jalan masuk invoice (checkout katalog, link WA tagihan, customer portal) karena halaman invoice-nya satu.
Opsi A — Langsung ke invoice REKOMENDASI

"Pesan Sekarang" → sukses → halaman invoice langsung terbuka + toast. 1 langkah lebih sedikit dari sekarang. Ini yang dimockup di atas.

Opsi B — Modal singkat, lalu auto-redirect

Modal "Pesanan Terkirim!" masih tampil 1,5 detik (nomor pesanan terbaca), lalu otomatis pindah ke invoice. Lebih pelan, tapi pesanan number sempat dilihat.
