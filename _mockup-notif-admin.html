Cara baca mockup & mapping ke kode
  1. Frame 1 (entry) — tombol sidebar "QRIS" ganti label jadi Notifikasi + badge angka unread. Badge dihitung dari kartu yang belum ditandai.
  2. Frame 2 (panel) — QrisHistoryModal.tsx di-rename jadi panel "Notifikasi Admin" dengan tab filter per tipe (Semua · 💳 QRIS · 🛒 Order · 🚚 Shipping, masing-masing berhitung unread) dan grup section di tab Semua:
    • Pembayaran (hijau) → QRIS Lunas (type: qris — data sudah ada di tabel notifications)
    • Order Masuk (pink) → Order Baru dari Katalog (CatalogOrderNotifier — saat ini cuma toast, kartu masuk ke riwayat juga)
    • Pengiriman (oranye) → Shopee Dipilih / No. Shopee Masuk / Kirim Manual (type: shipping, sudah ditulis pay.mjs:1479)
  3. State baca/tuntas — tabel notifications tidak punya kolom read → tandai di localStorage (id notif → timestamp), tanpa SQL/DDL. Sesudah 30 hari kartu anggap sudah dibaca.
  4. Tombol per kartu — Tandai selesai = tandai read + kartu jadi abu; Buka order = navigate ke url notif (/orders/... atau /invoice/...).
  5. Frame 3 (push + WA) — tidak berubah, hanya judul push mengikuti tipe.
  6. Kartu Order Baru masuk riwayat: saat ini cuma toast 10 detik lalu hilang — dengan panel ini ada jejak permanen + bisa dibuka ulang.
